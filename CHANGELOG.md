# Changelog

All notable changes to this project are documented here. This project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] – unreleased

### Added
- Device replacement wizard: old device → new device → entity matching → preview → apply.
- Scanner for automations, scripts, scenes and dashboards (values, scene keys, templates, legacy comma lists, device and entity-registry IDs).
- Safe apply: stale-preview check, Home Assistant validators, snapshot, reload, post-apply re-scan, automatic rollback on write failure.
- Undo from the result screen and from History.
- Admin-only WebSocket API and sidebar panel with light/dark theme and mobile layout.
